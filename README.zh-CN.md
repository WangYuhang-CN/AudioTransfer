# AudioTransfer

[English](./README.md) | [中文](./README.zh-CN.md)

AudioTransfer 是一个简单的 Windows 局域网声音传输工具。

它可以把一台电脑上的麦克风声音和系统声音发送到另一台电脑实时播放。

![AudioTransfer](./AudioTransfer_preview.png)

## 你可以用它做什么

- 把麦克风声音发到另一台电脑
- 把系统声音发到另一台电脑
- 同时发送麦克风和系统声音
- 用图形界面快速开始
- 用命令行做简单调试

## GitHub 发布
