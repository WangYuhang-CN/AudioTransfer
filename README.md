# AudioTransfer

[English](./README.md) | [中文](./README.zh-CN.md)

AudioTransfer is a simple Windows LAN audio transfer tool.

It can send microphone audio and system audio from one computer to another for real-time playback.

![AudioTransfer](./AudioTransfer_preview.png)

## What It Can Do

- Send microphone audio to another computer
- Send system audio to another computer
- Send microphone and system audio at the same time
- Start quickly with the GUI
- Debug with simple CLI tools

## GitHub Release

This repository includes a GitHub Actions release workflow.

- Creating a GitHub Release builds the Windows version automatically
- The built executable is uploaded to the Release as an asset
